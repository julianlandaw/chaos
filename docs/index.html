A FEW FIELD NOTES

There’s a method to the madness.

Stay curious. Keep turning the dial. ↙
01 / FIND THE FORK

Order has a tipping point.

At a growth rate of 2.8, the logistic map settles to one value. At 3.2, it alternates between two. Keep going and the branches split again. This is period doubling.

02 / CHANGE ALMOST NOTHING

Close isn’t always close enough.

Chaotic systems can amplify tiny differences in their starting points. The rules are exact; long-term prediction is the challenge. Try two pendulums that start almost identically.

03 / CHANGE YOUR PERSPECTIVE

Motion leaves a fingerprint.

Plot angle against angular velocity instead of time. A single pendulum traces a closed loop. A double pendulum’s two-dimensional projection reveals a much richer path.

04 / LET THE CELL REMEMBER

A heartbeat has a history.

A slow potassium-channel gate carries a memory of previous beats. In the LR1CellIto model, that memory can turn regular pacing into an irregular sequence of action-potential durations. An early afterdepolarization (EAD) is a secondary voltage rise before repolarization finishes.

THE FINE PRINT What’s happening under the hood?+

The logistic map

The normalized state x lives in [0, 1], with 0 ≤ a ≤ 4. The time series includes the initial transient; the bifurcation diagram discards 700 iterations and plots the next 160 for each sampled a, starting at x = 0.314159.

The displayed Lyapunov exponent estimates λ = (1/N) Σ ln |a(1 − 2xn)| using 2,048 iterations after a 1,000-step warm-up. Positive λ indicates local stretching on average. “No short cycle” means no period up to 64 was detected, not a proof of chaos. Periodic windows exist inside the chaotic region.

The cobweb follows vertical steps to y = ax(1 − x), then horizontal steps to y = x. It displays up to 60 iterations to keep the geometry readable. Nearby starts differ by 10−7.

The pendulums

Massless rigid rods, point masses, uniform gravity, and no friction or driving. Both angles are measured from the downward vertical. We solve the coupled equations with fixed-step fourth-order Runge–Kutta at Δt = 1/240 s.

(m₁+m₂)ℓ₁θ̈₁ + m₂ℓ₂ cos(δ)θ̈₂
= −m₂ℓ₂ sin(δ)θ̇₂² − (m₁+m₂)g sin θ₁

ℓ₁ cos(δ)θ̈₁ + ℓ₂θ̈₂
= ℓ₁ sin(δ)θ̇₁² − g sin θ₂
where δ = θ₁ − θ₂.

The nearby double pendulum differs by 0.01° in θ₂. The phase portrait plots (θ₂, θ̇₂) for each double pendulum and (θ, θ̇) for the single one, with angles wrapped to [−π, π]. It is a projection, not the full four-dimensional double-pendulum state. Energy drift helps you judge numerical accuracy; a simulated path is still an approximation.

INSIDE EXPERIMENT 03 From ionic currents to beat-to-beat chaos+

A paced map with a memory

This lab uses Julian Landaw’s LR1CellIto implementation of a modified Luo–Rudy I single-cell model. It evolves voltage, intracellular calcium, and ion-channel gates. Voltage follows Cm V̇ = −(INa + ICa,L + Ito + IKr + IK1 + IpK + Ib + Istim), with normalized Cm = 1 µF/cm² and currents in µA/cm².

The X-gate scale multiplies the time constant of xr, the activation gate of the delayed rectifier potassium current. Increasing it slows both activation and recovery without changing the steady state. The fast transient outward current changes the early plateau. Together, these mechanisms can make the next action potential depend strongly on the preceding beats.

The regular, chaos, and EAD presets reproduce the original simulator’s parameter sets. “Chaos” names the published parameter regime. APD variability or a scattered return map alone does not establish a positive Lyapunov exponent. This lab does not estimate one for the cardiac model.

What is actually measured?

Every run starts from the original initial state, rests unpaced for 10 seconds, and receives 10 conditioning beats before recording. A stimulus of −80 µA/cm² lasts 0.5 ms each pacing cycle. The original integration uses a 0.01 ms base step, exponential gate updates, and ten substeps when the proposed voltage change exceeds 0.1 mV.

APD is the interval between upward and downward crossings of −75 mV, measured at every integration step. It is a fixed-threshold duration, not APD90. Only completed APDs are plotted; their number can differ from the stimulus count when a response is blocked or spans multiple cycles. Return-map points pair successive completed APDs. The memory view pairs each APD with xr at its upstroke; it is an observed projection, not a fitted one-dimensional model.

The EAD counter follows the original rule: at least 100 ms after upstroke, a rise of 5 mV from a trough at or below −15 mV; a fall of 5 mV rearms the detector. It counts only completed action potentials. Voltage traces sample at 1 ms or coarser, with a 30,000-sample cap; APD and EAD detection still use every model step. The numerical run uses a worker on served pages and cooperative time slices for direct file access.

This is a deterministic single-cell model with fixed sodium and potassium concentrations and simplified calcium dynamics. It illustrates mechanisms within its equations; it does not simulate a whole heart or provide clinical predictions.
